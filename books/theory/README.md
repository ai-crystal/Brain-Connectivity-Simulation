# 连接组、动力学与仿真

> 把接线图写成方程，再把方程跑起来

这一册处理第一册留下的问题。有了接线图，怎样把它变成一个可以求解、可以运行、可以验证的系统。从霍奇金与赫胥黎的膜方程开始，经过突触动力学、网络稳定性、混沌与临界，最后落到参数辨识和保真度评估。 书中给出主要方程的推导与数值细节，也讨论每一步的代价。读者需要微积分、线性代数和常微分方程的基础，概率与图论的部分在正文中补齐。
