# 附录 B　术语中英对照

| 中文 | 英文 | 简要说明 |
| --- | --- | --- |
| 神经元 | neuron | 神经系统的基本细胞，负责接收、整合和传递信号 |
| 胶质细胞 | glia | 支持、绝缘和调节神经元的非神经元细胞 |
| 胞体 | soma | 神经元的细胞体，含细胞核和代谢机器 |
| 树突 | dendrite | 神经元接收输入的分支结构 |
| 轴突 | axon | 神经元传递动作电位的长纤维 |
| 突触 | synapse | 两个神经元之间的连接部位 |
| 突触间隙 | synaptic cleft | 突触前后膜之间约 20 纳米的缝隙 |
| 突触前 | presynaptic | 释放递质的一侧 |
| 突触后 | postsynaptic | 接收递质的一侧 |
| 神经递质 | neurotransmitter | 跨突触传递信号的化学分子 |
| 受体 | receptor | 结合递质并产生响应的膜蛋白 |
| 离子通道 | ion channel | 控制离子跨膜流动的膜蛋白 |
| 膜电位 | membrane potential | 细胞膜两侧的电位差 |
| 静息电位 | resting potential | 神经元未兴奋时的膜电位 |
| 动作电位 | action potential | 神经元发出的全或无的电脉冲 |
| 阈值 | threshold | 触发动作电位的膜电位水平 |
| 不应期 | refractory period | 放电后无法立即再次放电的时段 |
| 兴奋性 | excitatory | 使下游更容易放电的连接性质 |
| 抑制性 | inhibitory | 使下游更难放电的连接性质 |
| 神经调质 | neuromodulator | 调节神经元兴奋性和可塑性的递质 |
| 电突触 | electrical synapse | 通过缝隙连接直接传递电流的突触 |
| 缝隙连接 | gap junction | 连接相邻细胞胞质的通道结构 |
| 连接组 | connectome | 神经系统全部神经元与连接的完整图谱 |
| 突触权重 | synaptic weight | 连接的强度，常以突触数量近似 |
| 神经环路 | neural circuit | 一组相互连接的神经元执行特定功能 |
| 中央模式发生器 | central pattern generator | 能自发产生节律输出的神经环路 |
| 吸引子 | attractor | 动力系统长期趋向的状态 |
| 环形吸引子 | ring attractor | 用环形网络编码连续变量的结构 |
| 蘑菇体 | mushroom body | 昆虫的学习与记忆中心 |
| 肯扬细胞 | Kenyon cell | 蘑菇体的主要内在神经元 |
| 下降神经元 | descending neuron | 把大脑指令传到胸神经节的神经元 |
| 感觉神经元 | sensory neuron | 把外界刺激转换成神经信号的神经元 |
| 运动神经元 | motor neuron | 直接控制肌肉的神经元 |
| 中间神经元 | interneuron | 位于感觉和运动之间的神经元 |
| 漏电积分发放 | leaky integrate-and-fire | 最常用的简化神经元模型 |
| 霍奇金赫胥黎模型 | Hodgkin-Huxley model | 基于离子通道的电导模型 |
| 房室模型 | compartmental model | 把神经元切成多个电学隔室的模型 |
| 电缆方程 | cable equation | 描述电信号沿纤维衰减的方程 |
| 可塑性 | plasticity | 连接强度随活动改变的性质 |
| 脉冲时序依赖可塑性 | spike-timing-dependent plasticity | 根据放电先后调整突触的规则 |
| 钙成像 | calcium imaging | 用荧光指示剂记录神经元活动的技术 |
| 电子显微镜 | electron microscopy | 用电子束成像，分辨率可达纳米级 |
| 图像分割 | image segmentation | 从图像中分离出单个神经元的过程 |
| 校对 | proofreading | 人工修正自动分割错误的过程 |
| 膨胀显微 | expansion microscopy | 用可膨胀凝胶放大组织的成像方法 |
| 神经形态硬件 | neuromorphic hardware | 模仿神经系统结构的计算芯片 |
| 闭环 | closed loop | 感觉、计算、行动、反馈构成的回路 |
| 具身 | embodiment | 智能体拥有身体并与环境交互 |
| 保真度 | fidelity | 仿真与真实系统接近的程度 |
| 数字孪生 | digital twin | 与真实个体对应的计算模型 |
