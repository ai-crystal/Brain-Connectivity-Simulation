# 从神经元到果蝇大脑

> 从一只果蝇的脑讲起，把全脑仿真的来龙去脉说清楚

这一册从 2024 年那则新闻讲起。一只成年果蝇的完整大脑被逐突触测绘，随后被接到计算模型和虚拟身体上，出现了行走、理毛、趋近食物这些行为。新闻很短，背后的积累很长，从 1952 年的一根枪乌贼巨大轴突，到 1986 年线虫的 302 个神经元，再到电子显微镜自动化与自动分割算法的成熟。 全书按“大脑由什么组成、我们怎么看见它、看见之后怎么计算”的顺序展开，尽量不预设生物学或数学基础。读完之后，你应该能判断一篇全脑仿真的报道到底做到了哪一步，哪些是数据，哪些是模型假设，哪些还是宣传语。
