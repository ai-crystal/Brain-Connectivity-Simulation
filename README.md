# 全脑仿真

> 从果蝇大脑到数字心智

2024 年，一只成年果蝇的完整大脑被逐突触地测绘出来，约 13.9 万个神经元、5000 万个连接。有人把这套接线图接到计算模型上，让它在虚拟身体里走动、理毛、靠近食物。

书里从神经元、神经信号和成像技术讲起，经过连接组学的历史与现状，再讨论怎样把一张接线图变成可求解的方程、怎样评估仿真是否可信。
