# 全脑仿真

> 从果蝇大脑到数字心智

2024 年，一只成年果蝇的完整大脑被逐突触地测绘出来，约 13.9 万个神经元、5000 万个连接。紧接着，有研究团队把这套接线图接到计算模型上，让它在虚拟身体里走动、理毛、靠近食物。这类工作把一个问题重新摆到台面上，我们是否已经可以把一个真实的大脑搬到计算机里，让它在没有原始生物组织的情况下继续工作。

这套书回答这个问题。第一册《从神经元到果蝇大脑》从新闻出发，讲清楚神经元、神经信号、成像技术、连接组学的历史与现状，最后落到全脑仿真这件事本身，适合零基础读者通读。第二册《连接组、动力学与仿真》进入数学与模型层面，讨论怎样把一张接线图变成可求解的方程，怎样评估仿真是否可信，适合有理工科背景、想动手做模型的读者。

两册可以分开读。只想弄明白这件事的来龙去脉，读第一册就够了。想自己做仿真、调参数、判断一篇论文的模型是否站得住，第二册是主线。

## 怎么读

- 完全没接触过神经科学，从第一册第 1 章顺着读，不需要数学准备。

- 正在做连接组或神经形态计算，直接读第二册，遇到生物背景再回第一册查。
